# Custom Command Toggle Extension

This directory should contain the Custom Command Toggle extension files.

To get the actual extension files:
1. Install the extension from GNOME Extensions website
2. Copy the extension files from ~/.local/share/gnome-shell/extensions/custom-command-toggle@julian.gse.jsts.xyz/
3. Replace this placeholder directory

Required files:
- extension.js
- metadata.json
- prefs.js (if exists)
- schemas/ (if exists)
- Other extension files
