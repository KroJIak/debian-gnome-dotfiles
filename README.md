# 🎨 Debian GNOME Dotfiles

Красивая и функциональная конфигурация для Debian с GNOME, включающая все необходимые приложения, темы, расширения и настройки.

## 🚀 Быстрый старт

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/debian-gnome-dotfiles.git
cd debian-gnome-dotfiles

# Запустите установщик
./install.sh
```

## 📋 Что включено

### 🖥️ Системные настройки
- **Автоматическое масштабирование**: 125% для 2K+ экранов, 100% для FullHD
- **Отключение системных звуков** (звуки изменения громкости и т.д.)
- **Оптимизированные настройки GNOME** для лучшей производительности
- **Настройки клавиатуры и мыши** для комфортной работы

### 🎨 Темы и оформление
- **Тема DedSec для GRUB** - стильный загрузчик
- **Тема Cubes для Plymouth** - красивая заставка загрузки
- **Настроенные расширения GNOME** для улучшения интерфейса
- **Кастомные обои** высокого качества

### 📦 Приложения
- **Обязательные**: Fish shell, Kitty terminal, Flameshot, Neofetch, MPV
- **Дополнительные**: Docker, Chrome, Cursor, Discord, Arduino IDE
- **Snap пакеты**: PyCharm, IntelliJ IDEA, VS Code, Obsidian
- **Утилиты**: Color picker (gcolor3), системные инструменты

### 🔧 Расширения GNOME
- **Blur My Shell** - размытие фона
- **Just Perfection** - настройка интерфейса
- **Tiling Assistant** - помощник тайлинга окон
- **Vitals** - системная информация
- **Clipboard Indicator** - индикатор буфера обмена
- **Kando** - замена gnome-pie для быстрого доступа
- И многие другие...

## 📁 Структура проекта

```
debian-gnome-dotfiles/
├── 📄 install.sh              # Главный установщик
├── 📄 README.md               # Документация
├── 📁 assets/                 # Изображения и скриншоты
├── 📁 config/                 # Конфигурационные файлы
│   ├── fish/                  # Настройки Fish shell
│   ├── flameshot/             # Настройки Flameshot
│   ├── kitty/                 # Настройки Kitty terminal
│   └── neofetch/              # Настройки Neofetch
├── 📁 extensions/             # Расширения GNOME
│   ├── backup/                # Бэкапы расширений
│   └── UPDATE_EXTENSIONS.md   # Документация по расширениям
├── 📁 grub-theme/             # Тема для GRUB
├── 📁 home/                   # Домашние файлы (обои)
└── 📁 scripts/                # Скрипты установки
    ├── apps/                  # Установка приложений
    ├── custom/                # Кастомные настройки
    └── fixes/                 # Исправления системы
```

## 🛠️ Скрипты установки

### 📦 Приложения (`scripts/apps/`)
- `required_apps.sh` - Обязательные приложения
- `optional_apps.sh` - Дополнительные приложения
- `docker.sh` - Установка Docker
- `chrome.sh` - Установка Google Chrome
- `cursor.sh` - Установка Cursor IDE
- `snap.sh` - Настройка Snap
- `remove_trash.sh` - Очистка системы

### ⚙️ Настройки (`scripts/custom/`)
- `display_settings.sh` - Настройки дисплея и масштабирования
- `settings.sh` - Системные настройки GNOME
- `enable_extensions.sh` - Включение расширений
- `config.sh` - Копирование конфигураций
- `themes.sh` - Применение тем
- `grub/` - Настройка GRUB и Plymouth

### 🔧 Исправления (`scripts/fixes/`)
- `huawei_sound_fix/` - Исправление звука для Huawei

## 🎯 Особенности

### 🖥️ Умное масштабирование
Автоматически определяет разрешение экрана и устанавливает оптимальный масштаб:
- **2K+ экраны (2560px+)**: 125% масштаб
- **FullHD экраны (до 2560px)**: 100% масштаб

### 🔇 Отключение системных звуков
Автоматически отключает все системные звуки для тихой работы.

### 🎨 Красивые темы
- Современная тема DedSec для GRUB
- Стильная тема Cubes для Plymouth
- Оптимизированные настройки GNOME

### 📱 Мультизагрузка
Поддержка нескольких операционных систем:
- Debian (по умолчанию)
- Windows
- Ubuntu
- UEFI Settings

## 🔄 После установки

1. **Перезагрузите систему** для применения всех изменений
2. **Включите расширения**: `./scripts/custom/enable_extensions.sh`
3. **Настройте масштабирование**: `./scripts/custom/display_settings.sh`
4. **Проверьте работу** всех компонентов

## 🛠️ Управление GRUB

Используйте интерактивный менеджер для настройки GRUB:

```bash
./scripts/custom/grub/menu_manager.sh
```

**Возможности:**

- Создание бэкапов настроек
