# Настройка GRUB и Plymouth

Эта папка содержит скрипты для настройки загрузчика GRUB и темы Plymouth.

## Файлы

### `grub`
Основной конфигурационный файл GRUB с оптимизированными настройками для мультизагрузки.

**Основные настройки:**
- Система по умолчанию: Debian
- Таймаут: 7 секунд
- Включен os-prober для обнаружения других ОС
- Настроена тема DedSec
- Разрешение: 1920x1080
- Скрыты пункты восстановления

### `setup.sh`
Основной скрипт установки, который:
- Создает резервную копию текущих настроек
- Применяет новые настройки GRUB
- Устанавливает и настраивает тему Plymouth
- Обновляет конфигурацию GRUB и initramfs

**Использование:**
```bash
./setup.sh
```

### `menu_manager.sh`
Интерактивный менеджер для управления настройками GRUB.

**Возможности:**
- Просмотр текущих настроек
- Скрытие/показ пунктов восстановления
- Изменение таймаута загрузки
- Установка системы по умолчанию
- Создание бэкапов настроек
- Обновление конфигурации GRUB

**Использование:**
```bash
./menu_manager.sh
```

### `dedsec_theme.sh`
Скрипт для установки темы DedSec для GRUB.

**Функции:**
- Автоматическая установка Python3 (если не установлен)
- Скачивание темы с GitHub
- Установка темы
- Обновление конфигурации GRUB
- Очистка временных файлов

**Использование:**
```bash
./dedsec_theme.sh
```

## Обнаруженные операционные системы

В вашей системе обнаружены следующие операционные системы:
- **Debian** (по умолчанию)
- **Windows**
- **Ubuntu**
- **UEFI Settings**

## Рекомендации

1. **Перед применением изменений** всегда создавайте бэкап текущих настроек
2. **После изменения настроек** обязательно перезагружайте систему
3. **Используйте menu_manager.sh** для безопасного изменения настроек
4. **Проверяйте работоспособность** всех операционных систем после изменений

## Устранение неполадок

### Если GRUB не загружается:
1. Загрузитесь с Live USB
2. Восстановите бэкап: `sudo cp /etc/default/grub.backup.* /etc/default/grub`
3. Обновите GRUB: `sudo update-grub`

### Если тема не применяется:
1. Проверьте путь к теме: `/boot/grub/themes/dedsec/theme.txt`
2. Переустановите тему: `./dedsec_theme.sh`
3. Обновите GRUB: `sudo update-grub`

### Если не отображаются другие ОС:
1. Убедитесь, что `GRUB_DISABLE_OS_PROBER="false"`
2. Запустите: `sudo os-prober`
3. Обновите GRUB: `sudo update-grub`
